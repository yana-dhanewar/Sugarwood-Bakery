🌐 **[View Live Demo →](https://yana-dhanewar.github.io/Sugarwood-Bakery/premium/)**

---

## 📌 About the Project

Sugarwood Bakery is a front-end web application prototype designed to
demonstrate an end-to-end digital workflow for a bakery business.

The project covers both the **customer experience** and **business-side
operations**, connecting activities such as product discovery, custom
orders, checkout, order processing, fulfilment, customer communication,
promotions, and business analytics within one application.

The project was developed through an AI-assisted, iterative approach
involving requirements exploration, workflow design, implementation,
testing, debugging, and refinement.

## 🔄 End-to-End Workflow

The application demonstrates a complete workflow across the customer
and business sides:

**Customer**

Browse → Enquiry / Order → Cart → Checkout → Payment → Order Tracking
→ Delivery / Pickup → Review

**Business**

Order Received → Accept / Decline → Preparation → Fulfilment → Payment
Status → Customer Communication → Completion

The owner-side dashboard also supports ongoing operational activities
such as menu management, promotions, scheduling, customer enquiries,
and performance monitoring.

## 🧪 Demo Access

This project is a demonstration prototype. You can explore the
application using either the customer experience or the owner
dashboard.

### Customer

You can create your own customer account using the **Sign Up** option.

This is recommended because customer-specific information such as
orders, cart activity, notifications, and other account data is stored
locally in the browser for the demonstration.

### Owner

The owner dashboard can be accessed using the following **demo
credentials**:

**Username:** `owner`  
**Password:** `sugar123`

### Password Reset

Password recovery is simulated for demonstration purposes.

Since the prototype does not use a real email service, the OTP is
displayed within the application instead of being sent through email.

### ⚠️ Dummy Contact & WhatsApp

The contact information displayed throughout the application is
**dummy information created exclusively for demonstration purposes**.

The dummy phone number is also used for the application's WhatsApp
integration. Clicking the WhatsApp button will open WhatsApp and
attempt to start a conversation with that dummy number.

**Please do not send messages or calls to the displayed contact number.
It is not a real Sugarwood Bakery business contact and is used only to
demonstrate the functionality of the application.**

## ⚙️ Data & Application Architecture

The prototype uses browser-based local storage to simulate data
persistence across the application.

Examples of stored application data include:

- Customer accounts
- Orders
- Cart information
- Reviews
- Promotions
- Notifications
- Customer enquiries
- Conversations
- Operational tasks
- Business settings

This approach allows the application to demonstrate interactive
workflows without requiring a backend server.

---

## 🚧 Project Scope & Limitations

Sugarwood Bakery is a **demonstration prototype and is not intended
for production use**.

The following components are simulated for demonstration purposes:

- Authentication
- Password recovery
- Payment processing
- Data persistence
- Customer / owner communication
- Order management across users

No real financial transactions are processed, and no real email
service is connected to the password recovery flow.
